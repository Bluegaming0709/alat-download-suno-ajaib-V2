01 — Kantong Token BELUM LOGIN

CARA AMBIL TOKEN Buka suno.com, login. DevTools (F12) → tab Network. Klik request apa saja ke studio-api-prod.suno.com. Di Request Headers cari authorization: Bearer eyJ… Copy bagian eyJ… saja (tanpa kata "Bearer"), paste di bawah. Token Suno cuma hidup 1 jam. Kalau daftar lagu tiba-tiba kosong, ambil token baru.

02 — Lemari Lagu

Set token dulu, terus klik LOAD LAGU.

03 — Pintu Kemana Saja

Download 1 lagu langsung: paste UUID, URL suno.com/song/…, atau short link suno.com/s/…. Lagu publik jalan tanpa token.

Audio di-decrypt jadi file .m4a (format asli Suno, bukan mp3). Token kamu cuma dipakai dari browser kamu buat manggil Suno — nggak disimpan di server.
